应用场景

一个平台，覆盖校园四大拼单场景

🥤

日常生活拼单

奶茶、水果、零食…… 起送价太高？拉几个室友一起凑满减。

  • 分类发布（奶茶 / 水果）
  • 目标人数与截止时间
  • 满员自动成团
  • 成团即互见微信号
🎬

文娱拼单

两张电影票更划算，游戏组队找队友，陌生人也能快速拼到一起。

  • 关键词搜索 + 分类筛选
  • 陌生同学也能发现彼此
  • 成团后互加微信碰头
🚗

出行拼车

节假日拼车回家，写明目的地和出发时间，同路同学 AA 分摊路费。

  • 截止时间机制
  • 超时未满员自动结束
  • 成员退出人数自动回退
  • 出发前联系替补不泡汤
🎯

活动组队

社团统一采购道具、班级拼购、组团比赛……多人申请、团长集中审批。

  • 申请列表式管理
  • 批量审批入团
  • 成团统一对接收货分发

主要功能

五大模块，覆盖拼单全生命周期

用户中心 · 你的账号与身份

微信号必填、全程保密，账号安全由 BCrypt 加密守护。

📝 账号注册 用户名唯一校验 + 微信号必填，全程数据层置空保密。
🔐 登录 / 登出 UUID Token 鉴权，未登录 401 自动跳登录页。
👤 个人资料 查看昵称、微信号、角色权限，进入我的拼单。
🛡️ 密码加密 spring-security-crypto BCrypt 哈希存储，永不明文。

拼单中心 · 发布、浏览、详情

清爽列表不做状态轰炸，下拉选择状态、关键词搜索、分页加载。

➕ 发布拼单 标题、分类、描述、目标人数、截止时间一站搞定。
📋 默认展示招募中 首页只显示「招募中」，需要历史通过下拉切换。
🔍 关键词搜索 全文模糊匹配，分类下拉筛选（水果 / 奶茶 / 电影票 / 拼车 / 其他）。
📄 拼单详情 完整信息 + 当前成员名单 + 申请入口，微信号按规则显示。
📑 分页加载 每页 10 条，按创建时间倒序，状态轻量轮询刷新。
🎯 分类枚举 5 大预定义分类，保证数据规范、统计准确。

成团流程 · 申请 → 审批 → 自动成团

手写状态机管控，4 色状态标签可视化拼单生命周期。

招募中 RECRUITING
→
已成团 FORMED
→
已结束 FINISHED
↓
已取消 CANCELED
📨 申请加入 一键申请，写入待确认列表，团长可见。
✅ 团长审批 通过 / 拒绝两步操作，未通过自动失效。
🎉 满员自动成团 人数达标自动置「已成团」，停止接受申请。
⏰ 超时自动结束 Spring @Scheduled 每 5 分钟扫描，防止过期信息。
🔄 退出回退 成团前可主动退出，人数 -1；团长取消则所有申请失效。
📦 只改不删 业务数据物理不删，下架/取消均为状态变更，可追溯。

我的拼单 · 团长与成员双视角

两个 Tab 分得清清楚楚，Excel 导出便于留存统计。

📢 我发布的 查看申请列表、审批入团、取消 / 结束拼单。
🎒 我参加的 查看已加入的团，主动退出拼单。
📊 Excel 导出 Apache POI 一键导出两份列表，归档留存。
🔔 消息中心 申请结果、审批进度、成团通知实时推送。

运营管理 · 管理员后台

全站治理、看板可视化、敏感操作全程留痕。

👁️ 全站拼单 浏览全站拼单，强制下架违规内容。
🚫 禁用账号 禁用异常账号，普通用户与管理员权限严格隔离。
📈 数据看板 ECharts 图表：拼单总量（按状态分组）+ TOP 5 热门分类。
📜 操作日志 敏感操作自动记录（谁、什么时候、对什么做了什么）。

技术架构

前后端分层清晰，分工明确，可维护可扩展

前端

Vue 3.4 + Vant 4 + Vite 5

  • Vue 3.4 · Composition API + 响应式
  • Vant 4 · 移动端 UI 组件库
  • Axios · REST API + token 拦截器
  • ECharts 5 · 后台数据可视化
  • 路由懒加载 · 按需加载提速
  • 全局 Tabbar · 按路由 meta 显隐
后端

Spring Boot 3.2 + MyBatis + MySQL 8

  • Spring Boot 3.2 · 三层架构
  • Spring MVC · RESTful 接口
  • MyBatis 注解 · 手写 SQL，禁用 JPA
  • MySQL 8.0 · utf8mb4 字符集
  • UUID Token · 无状态鉴权
  • BCrypt · 密码哈希加密
工程化

Maven · Git · Apache POI · SpringDoc

  • Maven · 依赖与构建
  • Git · 版本管理
  • Apache POI · Excel 导出
  • SpringDoc · 自动生成接口文档
  • @Scheduled · 每 5 分钟超时扫描
  • 统一异常处理 · 全局 GlobalExceptionHandler
